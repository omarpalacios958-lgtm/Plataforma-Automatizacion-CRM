# Plataforma Web para Automatización de Comunicación Empresarial

## Descripción

Sistema web desarrollado como proyecto de residencia profesional para automatizar la comunicación con clientes y prospectos mediante un CRM con funcionalidades de seguimiento, automatización y generación de reportes.

## Tecnologías

- React + Vite
- Node.js + Express
- PostgreSQL
- Prisma ORM
- JWT
- Git

## Arquitectura

- Frontend
- Backend
- Base de datos
- API REST
